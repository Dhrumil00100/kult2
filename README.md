# KULT Salon Website

## Overview

KULT Salon Website is a modern, responsive, and user-friendly salon management and booking platform designed to help salons showcase their services, attract customers, and streamline appointment scheduling. The website provides an elegant digital presence for the salon while allowing customers to browse services, view pricing, explore galleries, and book appointments online.

The platform focuses on delivering a premium user experience, increasing customer engagement, and improving business efficiency through digital transformation.

# Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/kult-salon.git
```

## Navigate to Project

```bash
cd kult-salon
```

## Install Dependencies

```bash
npm install
```

## Create Environment File

Create a `.env` file in the root directory:

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

CLOUDINARY_CLOUD_NAME=your_cloud_name

CLOUDINARY_API_KEY=your_api_key

CLOUDINARY_API_SECRET=your_api_secret
```

## Start Development Server

Frontend:

```bash
npm run dev
```

Backend:

```bash
npm start
```
